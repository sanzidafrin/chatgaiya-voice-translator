About the Project

Chatgaiya Voice Translator is an academic artificial intelligence project designed to recognize spoken Chittagonian dialect and generate its corresponding written Standard Bangla transcription. The system uses a fine-tuned Whisper-based automatic speech recognition model.

Key Features

Audio Upload

Upload an audio recording containing spoken Chittagonian dialect.

Voice Recording

Record speech directly through your device's microphone.

AI Translation

Generate written Standard Bangla from Chittagonian speech.

Technology Stack

Python · PyTorch · Hugging Face Transformers · Whisper · PEFT / LoRA · Gradio · Google Colab
